# §2 注释规范

> 本项目是 Java/C++ 联合项目。注释系统**强制使用 doxygen-javadoc 子集**，
> 并带有本项目的特殊约定 (§2.2 / §2.3)。服务于 T0[2] (长期可维护)。

---

## §2.1 通用规则

- **注释语言：全项目代码注释统一使用英文** (标识符、伪代码标识符本就英文)。
  规约文档本身用中文，代码内注释一律英文，禁止中英混杂。
- 函数 (方法)、类 (含结构体) 的文档注释**统一使用 `/** ... */` 块注释**，
  **禁止使用多行 `///`**。
- 所有函数使用 `@param` 标注**每一个**参数，**必须显式给出参数的数据类型与参数名**，
  参数名语义完整、**不得缩写** (与 §1.1.2 一致)。
- 有返回值的函数使用 `@return`；可抛出异常 (Java) / 可返回错误码 (C++) 须用
  `@throws` / `@return` 明确说明失败语义与边界。
- 注释描述**功能与边界** (前置/后置条件、取值范围、非法输入行为)，不是复述代码。

---

## §2.2 @brief 的语言差异约定 (※特殊约定※)

- **C++：** 使用 `@brief` 写明函数功能及边界。
- **Java：** Javadoc 无 `@brief`，因此**直接在注释最前部分**写明方法功能及边界
  (不加 `@brief` 标签)。

---

## §2.3 自定义规约 (※本项目强制※)

因项目涉及 C++/Vulkan 多线程指令录制与调度、Java/C++ 的 JIT 编译，
以下两条自定义标签为**强制**：

### `@note ThreadSafety` —— 线程安全显式说明 (**必须在注释首行标出**)

- 说明该 Panama 调用的 C++ 库/函数**是否支持并发**、在何种约束下并发安全。
- **位置要求：该说明必须是文档注释的首行内容** (紧随功能描述之前或作为首个标签，
  确保调用者第一眼即可见)。

### `@warning MemoryOwnership` —— 内存所有权归属

- 明确 C++ 返回的指针 / Java 传入的 `MemorySegment` **由谁负责释放**，
  以及 `Arena` 的生命周期由谁管理。
- 凡跨 Java↔Native 边界传递内存的函数，此标签**必填**。

---

## §2.4 关键算法注释 (与 §1.3 联动)

关键算法实现处，注释须包含**算法原理**与**语义完整的伪代码**。伪代码标识符同样禁止缩写。

---

## §2.5 模板示例

### C++ 示例

```cpp
/**
 * @note ThreadSafety: Concurrency-safe. A single CommandRecorder instance may be
 *       called concurrently by multiple recording threads; state is lane-partitioned
 *       with no shared mutable data. No cross-instance synchronization is required.
 * @brief Records one prebuilt draw primitive into the command buffer of a given lane.
 *        Edge case: when vertexCount is 0 this is a no-op and returns true.
 * @param commandBuffer Target command buffer handle (caller guarantees recording state)
 * @param vertexCount   Number of vertices, range [0, UINT32_MAX]
 * @param firstVertex   Offset of the first vertex
 * @return bool True on successful recording; false when the handle is invalid.
 * @warning MemoryOwnership: Ownership of commandBuffer stays with the caller; this
 *          function neither releases it nor extends its lifetime.
 */
bool recordDrawCommand(VkCommandBuffer commandBuffer,
                       uint32_t vertexCount,
                       uint32_t firstVertex);
```

### Java 示例

```java
/**
 * @note ThreadSafety: Not thread-safe. This method accesses a shared Arena; callers
 *       must serialize access, or use a per-thread compilation context instance.
 * Resolves the downcall handle for a graph node and binds it as a constant into the
 * generated bytecode.
 * Boundary: throws UnknownNodeException when nodeTypeIdentifier is not registered
 * in the loader.
 *
 * @param long nativeFunctionAddress Resolved native function entry address
 * @param String nodeTypeIdentifier  Graph node type identifier
 * @return MethodHandle A monomorphic downcall handle bound to the native function
 * @throws UnknownNodeException When nodeTypeIdentifier is not registered
 * @warning MemoryOwnership: The Arena backing the returned MethodHandle is owned by
 *          this compilation context and shares its lifetime; callers must not cache
 *          the handle across compilation contexts.
 */
MethodHandle resolveDowncallHandle(long nativeFunctionAddress,
                                   String nodeTypeIdentifier);
```

> 注：Java 的 `@param` 形如 `@param <类型> <参数名> <说明>`，以满足"显式给出数据类型"
> 的要求 (Javadoc 原生不带类型，故类型写入标签正文)。此为本项目约定，全项目统一。
